# DataHub Agent for Dataverse 1.4.0-rc1

- Provides the release candidate for the Dataverse agent packages aligned
  with DataHub 1.4.0, the Core Agent 1.4.0-rc1 packages, and .NET 10.
- Introduces `Reimaginate.DataHub.Agent.Dataverse` as the replacement for
  `Reimaginate.DataHub.D365Agent`.
- Introduces `Reimaginate.DataHub.Agent.TestFramework.Dataverse` as the
  replacement for `Reimaginate.DataHub.TestFramework.Agents.D365CE`.
- Publishes buildable MIT-licensed source and safe unit tests in the dedicated
  Dataverse release mirror.
