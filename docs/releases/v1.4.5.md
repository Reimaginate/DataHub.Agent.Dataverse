# DataHub Agent for Dataverse 1.4.5

- Resolves DataHub alternate keys using the configured Dataverse data-source
  prefix instead of assuming the `dataverse` prefix.
- Preserves compatibility with existing `d365` alternate keys as a fallback
  when a custom data-source name is configured.
- Adds unit coverage for configured, case-insensitive, logical-name and legacy
  alternate-key resolution and for the missing-key failure path.
- Updates DataHub and Core Agent dependencies to 1.4.1, Microsoft.Extensions
  dependencies to 10.0.11, Microsoft.Azure.Cosmos to 3.62.1 and Testcontainers
  dependencies to 4.14.0.
