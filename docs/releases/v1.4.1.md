# DataHub Agent for Dataverse 1.4.1

- Fixes Dataverse synchronization to consistently use the configured
  `DataSource` for alternate keys, tracking updates, sync allow/block lists,
  deletion handling, referenced entities, and resolution promises instead of
  assuming the source is named `Dataverse`.
- Supports configured aliases such as `D365` while remaining compatible with
  DataHub 1.4.0, Core Agent 1.4.0, and .NET 10.
- Corrects the Dataverse test-framework package so its shared test-support
  assembly is included directly instead of appearing as an unpublished NuGet
  dependency.
