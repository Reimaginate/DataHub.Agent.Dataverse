# DataHub Agent for Dataverse 1.4.0-rc4

- Clarifies that the Dataverse Agent source and official package content are
  licensed under MIT while DataHub dependencies retain their separate BUSL
  licence.
- Adds generated third-party dependency notices to the public source snapshot
  and NuGet packages.
- Restricts full DataHub hosting dependencies and namespaces to Dataverse
  integration-test support.
- Aligns with DataHub 1.4.0, the Core Agent 1.4.0-rc4 packages, and .NET 10.
