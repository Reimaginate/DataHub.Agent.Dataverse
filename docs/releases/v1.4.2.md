# DataHub Agent for Dataverse 1.4.2

- Fixes merge-failure reporting so DataHub receives the required failure type
  and reason while retaining the description used by notifications.
- Reports `SourceEntityNotFound` only for records that Dataverse identifies as
  missing and includes a descriptive reason for each missing record.
- Remains compatible with DataHub 1.4.0, Core Agent 1.4.0, and .NET 10.
