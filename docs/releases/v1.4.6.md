# DataHub Agent for Dataverse 1.4.6

- Adds chainable Dataverse test-agent helpers for asserting that a DataHub
  record sync returns no result, using either a supplied record or a stashed
  record.
- Reports sync failures directly while distinguishing unexpected successful
  results from the expected empty response.
- Adds unit coverage for dispatch, scenario-state preservation, empty responses,
  unexpected successful responses and sync failures.
