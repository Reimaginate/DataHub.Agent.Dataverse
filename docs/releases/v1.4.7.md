# DataHub Agent for Dataverse 1.4.7

- Preserves every detected Dataverse field difference when preparing outbound
  updates, preventing partial updates from omitting changed fields.
- Removes unsafe concurrent writes from synchronous in-memory entity comparison
  while retaining cancellation checks between compared fields.
- Adds regression coverage for replacing, clearing, adding and retaining mapped
  values, repeated multi-field comparisons, and comparison cancellation.
