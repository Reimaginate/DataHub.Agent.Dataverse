# DataHub Agent for Dataverse 1.4.3

- Prevents repeated merge-failure results for the same Dataverse source entity
  from causing a null-reference failure while processing updated entities.
- Preserves the failed sync outcome and latest merge-failure reason when a
  repeated result is reported.
- Publishes the cumulative release-note history in the generated public source
  repository.
- Remains compatible with DataHub 1.4.0, Core Agent 1.4.0, and .NET 10.
