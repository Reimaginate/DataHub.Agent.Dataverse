# DataHub Agent for Dataverse 1.4.8

- Refreshes referenced entities after Dataverse reconciliation so newly introduced
  Owner references resolve before outbound business updates are mapped.
- Preserves existing User and Team identities, explicit Owner clearing, external
  references, and unchanged-record behavior. Reference failures affect only the
  relevant record; cancellation stops processing.
- Updates DataHub dependencies to 1.4.12, Dataverse Client to 1.2.27, and the
  Microsoft, Azure, cryptography, and test-support maintenance dependencies.
- Uses ProcessingLock 4.0 with its separate Redis provider and releases acquired
  locks even when the processing request is cancelled.
- Adds 23 reconciliation regression cases and five ProcessingLock compatibility
  cases. All 86 Dataverse unit tests and the S1001 live integration test passed
  during validation.

Consumers that configure ProcessingLock directly must use the 4.0-compatible
packages and Redis registration API. Full DataHub runtime consumers must use
DataHub 1.4.12 or a later compatible release.
