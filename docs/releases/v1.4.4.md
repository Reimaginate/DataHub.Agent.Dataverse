# DataHub Agent for Dataverse 1.4.4

- Prevents transient or partial Data Hub alternate-key registration failures
  from causing duplicate Dataverse records on a later synchronization.
- Correctly correlates each alternate-key registration response with its
  corresponding Data Hub entity and withholds source tracking for registrations
  that remain unsuccessful.
- Retries only failed or missing alternate-key registrations using a bounded
  Polly resilience pipeline with configurable exponential backoff and jitter.
- Adds regression coverage for partial registration recovery and verifies that
  a subsequent synchronization reuses the original Dataverse record.
- Remains compatible with DataHub 1.4.0, Core Agent 1.4.0, and .NET 10.
