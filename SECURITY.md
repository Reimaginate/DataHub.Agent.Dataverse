# Security

Do not report security vulnerabilities through public GitHub issues.

Use **Report a vulnerability** on this repository's Security page to submit a
private GitHub vulnerability report.

If private reporting is unavailable, send the report to
[support@reimaginate.online](mailto:support@reimaginate.online).

Include the affected package and version, impact, reproduction details, and
any known mitigations. Do not include credentials, customer data, or other
secrets in a public issue.
