# Reimaginate.DataHub.Agent.Dataverse

Microsoft Dynamics 365 Customer Engagement integration agent for Reimaginate DataHub synchronization, merge processing, and Dataverse access.

## Package

This package provides the runtime agent services, request handlers, data access commands, and configuration extensions used to connect Reimaginate DataHub workflows to Dynamics 365 Customer Engagement.

Source: https://github.com/Reimaginate/DataHub.Agent.Dataverse

Support: support@reimaginate.online
