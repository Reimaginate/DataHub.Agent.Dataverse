# Reimaginate.DataHub.Agent.TestFramework.Dataverse

Test framework agent helpers for exercising Reimaginate DataHub Dynamics 365 Customer Engagement integrations.

## Package

This package provides test-agent helpers and filter utilities for arranging, querying, updating, and cleaning up Dynamics 365 Customer Engagement records in DataHub integration tests.

Source: https://github.com/Reimaginate/DataHub.Agent.Dataverse

Support: support@reimaginate.online
